    Structured data basics

    What Is Schema Markup?

    Schema Markup is a standardized semantic vocabulary created by Schema.org that describes the entities on a webpage, such as businesses, products, articles, events, recipes, and videos, in a machine-readable format that search engines can parse reliably alongside your visible page content.

    Frequently asked questions

    Frequently Asked Questions

    1. What is Schema Markup? +

    Schema Markup is standardized structured data code based on the Schema.org vocabulary that explicitly tells search engines what your webpage content represents, such as an organization, product, article, event, or video.

    2. What is JSON-LD? +

    JSON-LD (JavaScript Object Notation for Linked Data) is a lightweight linked-data format placed inside a <script type="application/ld+json"> block. It is Google's recommended structured data format because it separates data from visible HTML tags.

    3. How do I generate Schema Markup? +

    Choose a schema type in the selector above, enter your page's genuine information, review the live JSON syntax and Schema.org validation checks on the right, and copy or download the generated JSON-LD code.

    4. Which Schema.org types are supported? +

    Open Sign supports 12 core types and subtypes: Organization, LocalBusiness (including Restaurant, Store, MedicalBusiness, LegalService, and more), Product, Article (Article, NewsArticle, BlogPosting), FAQPage, BreadcrumbList, Event, Person, WebSite, WebPage, Recipe, and VideoObject.

    5. What is the difference between Schema.org and JSON-LD? +

    Schema.org is the vocabulary (the types and property names like "Product", "offers", or "author"), while JSON-LD is the encoding syntax used to express that vocabulary inside your webpage.

    6. Does Schema Markup improve SEO? +

    Structured data helps search engines understand your page entities more accurately and can make eligible pages qualify for enhanced search appearances, though adding schema markup is not a direct ranking guarantee.

    7. How do I validate structured data? +

    First check the live JSON Syntax and Schema.org Vocabulary status in Open Sign, then test your generated code or live URL using Google's Rich Results Test and the official Schema.org Validator linked above.

    8. Is FAQ Schema eligible for Google rich results? +

    Google currently restricts FAQ rich results in search primarily to well-known, authoritative government and health websites. Commercial and general websites can still include accurate FAQPage JSON-LD to describe their Q&A structure, without expecting FAQ rich snippets in Google.

    9. Can I use multiple Schema Markup types on one page? +

    Yes. A single webpage can include multiple <script type="application/ld+json"> blocks (for example, BreadcrumbList alongside Article or Product) as long as every schema accurately reflects visible content on that page.

    10. Where should I add JSON-LD code? +

    Paste the <script type="application/ld+json">...</script> snippet inside the <head> section (or within the <body>) of your HTML page, or inject it via your CMS or tag manager.

    11. Is Open Sign Schema Markup Generator free? +

    Yes. It is 100% free to use directly in your browser with no account required, and none of your schema inputs are uploaded or stored on any server.

    12. Does valid Schema Markup guarantee rich results? +

    No. Valid Schema.org JSON-LD is required for eligibility, but Google decides whether to display rich results based on search query context, device type, content quality guidelines, and supported feature policies.
