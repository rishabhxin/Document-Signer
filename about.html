Open Source · Privacy First

Built for private,
effortless signing.

Open Sign is an open-source, browser-based PDF signing platform. We believe signing a document should take seconds—without mandatory accounts, subscriptions, or handing sensitive files over to remote servers.

Open source by default

Every line of Open Sign is publicly available on GitHub. Inspect how your documents are handled, report issues, contribute improvements, or self-host your own instance with zero vendor lock-in.

Your documents stay yours

Rendering, signing, and PDF export happen entirely inside your browser. Nothing is uploaded to external servers, stored in a database, or tracked with third-party analytics.

Local Smart Sign detection

Smart Sign scans uploaded contracts locally—using PDF text geometry and in-browser OCR for scanned pages—to suggest signature, name, date, and initials fields that you review and approve before signing.

Less interface. More experience.

No cluttered dashboards or multi-step sign-up walls. Drop a PDF, draw, type, or upload your signature, place text or dates with precision, and download a clean signed PDF right away.

Transparent, zero-backend architecture

Open Sign runs on lightweight web standards and battle-tested open-source libraries so it works directly in any modern browser.

Rendering & Analysis PDF.js + Web Workers Client-side page rendering and non-blocking text/layout extraction.
Document Export pdf-lib Embeds signatures and text locally while preserving original dimensions and orientation.
Scanned PDF Support Tesseract.js (Local OCR) Loaded on demand only for image-based pages—no external AI APIs.
Source Code Open Source on GitHub Vanilla HTML, CSS, and JavaScript—easy to audit, customize, and deploy anywhere.
